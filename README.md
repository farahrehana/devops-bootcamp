Topik yang dipelajari:

- Membina repositori Git.
- Menggunakan `git add` dan `git commit`.
- Mengurus branch.
- Menyelesaikan merge conflict.
- Push perubahan ke GitHub.

### 2. AWS — EC2, IAM, SSM dan S3

Aktiviti yang dilakukan:

- Melancarkan EC2 instance.

- Mengakses EC2 melalui AWS Systems Manager Session Manager.
- Menyenaraikan EC2 instance menggunakan AWS CLI.
- Menyenaraikan S3 bucket menggunakan AWS CLI.
- Menyimpan output latihan dalam fail `aws2/notesnike.mdbal`.

> Nota: Maklumat sensitif seperti AWS Secret Access Key dan private key.pem` tidak disimpan di dalam repositori ini.

## Arahan Git Asas

| Arahan | Fungsi |
|---|---|
| `git init` | Membina repositori Git baharu |
| `git status` | Memeriksa status fail |
| `git add .` | Menambah semua perubahan ke staging |
| `git commit -m "message"` | Menyimpan perubahan dalam Git |
| `git branch` | Melihat senarai branch |
| `git checkout -lac branch-name` | Membina dan berpindah ke branch baharu |
| `git pull` | Mengambil perubahan terbaru dari GitHub |
| `git push` | Menghantar perubahan ke GitHub |
| `git log --oneline` | Melihat sejarah commit secara ringkas |
